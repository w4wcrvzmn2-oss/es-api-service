# ES API Service - Веб-клиент

Веб-интерфейс для тестирования ES API Service - сервиса экспорта данных из MS SQL Server.

## Описание

Этот веб-клиент предоставляет удобный графический интерфейс для:
- Авторизации в API сервисе
- Тестирования различных параметров запросов
- Просмотра результатов в удобном формате
- Экспорта данных в JSON файлы
- Мониторинга состояния сервиса

## Файлы

- `index.html` - Основная HTML страница с интерфейсом
- `styles.css` - CSS стили для красивого оформления
- `script.js` - JavaScript логика для работы с API
- `README.md` - Данная документация

## Возможности

### 🔐 Авторизация
- Вход с именем пользователя и паролем
- Автоматическое сохранение настроек в localStorage
- Отображение статуса авторизации

### 📊 Запросы данных
- Выбор таблицы (es_ef2, es_producer)
- Настройка лимита записей (1-100,000)
- Установка смещения для пагинации
- Фильтрация по дате обновления
- Инкрементальная выгрузка по ID
- Выбор конкретных колонок
- Кнопка "Сейчас" для быстрой установки текущего времени

### 📈 Результаты
- Красивое отображение JSON данных
- Подсчёт количества полученных записей
- Экспорт данных в JSON файл
- Прокрутка для больших результатов

### 🔍 Мониторинг
- Проверка состояния сервиса (/healthz)
- Автоматическая проверка при загрузке страницы
- Отображение статуса подключения

## Использование

### 1. Запуск клиента

Откройте файл `index.html` в веб-браузере. Клиент работает полностью на стороне клиента и не требует веб-сервера.

### 2. Настройка подключения

1. Введите URL API сервиса (по умолчанию: `http://localhost:8080`)
2. Введите имя пользователя и пароль из конфигурации сервиса
3. Нажмите "Войти"

### 3. Тестирование API

1. Выберите таблицу для запроса
2. Настройте параметры запроса:
   - **Лимит записей**: количество записей для получения
   - **Смещение**: для пагинации
   - **Обновлено после**: фильтр по дате (RFC3339 формат)
   - **ID больше чем**: для инкрементальной выгрузки
   - **Колонки**: список колонок через запятую
3. Нажмите "Получить данные"

### 4. Работа с результатами

- Просматривайте данные в удобном JSON формате
- Используйте экспорт для сохранения данных в файл
- Очищайте результаты для новых запросов

## Технические детали

### Поддерживаемые браузеры
- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

### CORS
При тестировании с локальными файлами может возникнуть ошибка CORS. Решения:
1. Запустите простой HTTP сервер: `python -m http.server 8000`
2. Откройте `http://localhost:8000` вместо файла
3. Или используйте браузер с отключенной проверкой CORS

### Безопасность
- Токены JWT хранятся только в памяти браузера
- Пароли не сохраняются
- Все запросы идут через HTTPS (рекомендуется)

## Устранение неполадок

### Ошибка CORS
**Проблема**: Браузер блокирует запросы из-за политики CORS
**Решение**: Используйте HTTP сервер или настройте CORS на сервере

### Ошибка подключения
**Проблема**: Не удается подключиться к API
**Решение**: 
1. Проверьте, что сервис запущен
2. Проверьте правильность URL
3. Проверьте настройки firewall

### Ошибка авторизации
**Проблема**: 401 Unauthorized
**Решение**:
1. Проверьте правильность логина/пароля
2. Проверьте, что токен не истек
3. Попробуйте перелогиниться
