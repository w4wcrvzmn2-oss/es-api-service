# Использование таблицы Region в веб-клиенте

## Обновления
В веб-клиент добавлена поддержка таблицы **Region** с данными о 85 регионах России.

## Как использовать

### 1. Запуск сервисов
```bash
# Терминал 1: API сервис
cd C:\MyPRJ\elfAPI
.\es_api_service.exe

# Терминал 2: Веб-клиент  
cd C:\MyPRJ\elfAPI\ClientWeb
python -m http.server 3000
```

### 2. Открытие веб-клиента
Откройте браузер и перейдите по адресу: `http://localhost:3000`

### 3. Авторизация
- **Имя пользователя:** `admin`
- **Пароль:** `admin123`
- **URL API:** `http://localhost:8080`

### 4. Запрос данных о регионах

#### Выбор таблицы
В выпадающем списке "Таблица" выберите **Region**

#### Параметры запроса
- **Лимит записей:** количество регионов (по умолчанию 100)
- **Смещение:** для пагинации (начните с 0)
- **Колонки:** выберите нужные поля:
  - `Code` - код региона (01-92)
  - `Name` - название региона
  - `Capital` - столица/административный центр
  - `FederalDistrict` - федеральный округ
  - `IsActive` - признак активности
  - `CreatedAt` - время создания
  - `UpdatedAt` - время обновления

#### Примеры запросов

**Все регионы:**
- Таблица: Region
- Лимит: 100
- Колонки: (оставить пустым)

**Только названия и столицы:**
- Таблица: Region
- Лимит: 10
- Колонки: `Name,Capital`

**Регионы с кодами и федеральными округами:**
- Таблица: Region
- Лимит: 20
- Колонки: `Code,Name,FederalDistrict`

**Пагинация:**
- Таблица: Region
- Лимит: 10
- Смещение: 20
- Колонки: `Code,Name`

### 5. Результаты
Данные будут отображены в формате JSON в панели "Результаты".

## Структура данных Region

| Поле | Тип | Описание |
|------|-----|----------|
| RegionID | GUID | Уникальный идентификатор |
| Code | NVARCHAR(10) | Код региона (01-92) |
| Name | NVARCHAR(200) | Название региона |
| FederalDistrict | NVARCHAR(100) | Федеральный округ |
| Capital | NVARCHAR(100) | Столица/административный центр |
| IsActive | BIT | Признак активности |
| CreatedAt | DATETIME2 | Время создания |
| UpdatedAt | DATETIME2 | Время обновления |

## Примеры данных

```json
[
  {
    "RegionID": "12345678-1234-1234-1234-123456789012",
    "Code": "01",
    "Name": "Республика Адыгея",
    "FederalDistrict": "Южный",
    "Capital": "Майкоп",
    "IsActive": true,
    "CreatedAt": "2024-01-01T00:00:00Z",
    "UpdatedAt": "2024-01-01T00:00:00Z"
  }
]
```
