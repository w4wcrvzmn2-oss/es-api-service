# ES API Service - Клиентское приложение

## Структура приложения

Приложение разделено на отдельные страницы для удобной навигации:

### 📄 Страницы

1. **login.html** - Страница авторизации
   - Вход в систему
   - Настройка URL API
   - Сохранение учетных данных

2. **index.html** - Главная страница (Dashboard)
   - Информация об аккаунте
   - Быстрые действия
   - Статистика
   - Навигационное меню

3. **api-test.html** - Проверка API
   - Проверка состояния сервиса
   - Запросы данных из таблиц
   - Экспорт JSON

4. **matching.html** - Сопоставление прайсов
   - Запуск сопоставления импортированных данных
   - Выбор импорта для обработки

5. **price-lists.html** - Управление прайсами
   - Создание и редактирование прайс-листов
   - Управление поставщиками
   - Управление точками импорта
   - Маппинг полей DBF
   - Импорт файлов прайсов
   - Настройка регионов действия
   - Настройка наценок и расписания обновления

6. **price-summary.html** - Сводный прайс
   - Просмотр всех прайсов поставщика
   - Сводный прайс с последними ценами
   - Фильтрация по поставщику или всех поставщиков

### 📁 Файлы JavaScript

- **auth.js** - Модуль авторизации и управления сессией
- **api-test.js** - Скрипт для страницы проверки API
- **price-lists.js** - Скрипт для страницы управления прайсами (включая импорт прайсов)
- **matching.js** - Скрипт для страницы сопоставления
- **price-summary.js** - Скрипт для страницы сводного прайса

### 🎨 Стили

- **styles.css** - Общие стили приложения

## Использование

1. Откройте `login.html` в браузере
2. Введите учетные данные (по умолчанию: admin/admin123)
3. После авторизации откроется главная страница
4. Используйте навигационное меню для перехода между разделами

## Функциональность

### Авторизация
- JWT токены сохраняются в localStorage
- Автоматическая проверка авторизации на каждой странице
- Сохранение настроек API URL

### Проверка API
- Health check сервиса
- Запросы к таблицам базы данных
- Фильтрация и пагинация
- Экспорт результатов в JSON

### Управление прайсами (включая импорт прайсов)
- Создание и редактирование прайс-листов
- Управление поставщиками
- Управление точками импорта
- Анализ DBF файлов
- Настройка маппинга полей
- Запуск импорта данных
- Настройка регионов действия
- Настройка наценок и расписания обновления

### Сопоставление
- Выбор импорта для обработки
- Запуск автоматического сопоставления с справочником препаратов
- Мониторинг процесса

### Сводный прайс
- Просмотр всех прайсов поставщика
- Сводный прайс с последними ценами
- Фильтрация по поставщику или всех поставщиков

## Технические детали

- Используется localStorage для хранения токена и настроек
- Все API запросы проходят через AuthManager для автоматической авторизации
- Автоматический редирект на страницу логина при истечении сессии
- Адаптивный дизайн для разных размеров экрана
